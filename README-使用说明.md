# 滑动同步 SwipeSync — 使用说明

> 手表（Redmi Watch 6）上下左右滑动 → 手机（小米17 Pro Max）同步执行滑动手势
> 适用：刷短视频翻页、阅读翻页、相册切换、音乐切歌等"滑动=切换"场景

---

## 一、交付物清单

| 文件 | 说明 |
|---|---|
| `SwipeSync-1.0.0.apk` | 手机端（小米17 Pro Max / 澎湃OS 3） |
| `com.swipesync.app.debug.1.0.0.rpk` | 手表端快应用（Redmi Watch 6 / 澎湃OS） |

⚠️ 两个包必须**配套安装**：它们使用同一包名 `com.swipesync.app` 与同一签名证书，
这是小米穿戴 interconnect 通信的硬性要求（包名或签名不一致则无法通信）。

---

## 二、安装步骤

### 1. 手机端 APK
直接安装 `SwipeSync-1.0.0.apk`（允许"未知来源"安装）。

### 2. 手表端 RPK（三选一）

**方式 A：小米运动健康（推荐，不影响手表连接）**
1. 打开小米运动健康 App
2. 进入「我的」→「关于」→ 连续点击版本号开启 Debug 菜单
3. Debug → 第三方应用 → **Install third app** → 输入包名 `com.swipesync.app`
4. 选择 `com.swipesync.app.debug.1.0.0.rpk` 安装，提示成功即可

**方式 B：AstroBox（社区工具）**
1. 手机安装 AstroBox（https://astrobox.online/ ），登录绑定手表的小米账号
2. 安装包传输期间需临时「强制停止」小米运动健康（仅安装期间，装完恢复）
3. 选择 `com.swipesync.app.debug.1.0.0.rpk` 推送安装
4. 安装完成后重新打开小米运动健康恢复配对

**方式 C：AIoT-IDE 真机调试**
用 AIoT-IDE 连接手表直接安装调试（适合开发者）。

## 三、手机端配置（一次性）

1. **开启无障碍服务**：打开 App → 点「开启无障碍」→ 在系统设置中开启
   「滑动同步手势注入」→ 返回 App，状态显示"已开启"
2. **启动同步服务**：点「启动同步服务」，状态显示"运行中"
3. **保活设置（重要，保证后台运行）**：
   - 系统设置 → 应用设置 → 滑动同步 → 自启动：**开**
   - 系统设置 → 应用设置 → 滑动同步 → 省电策略：**无限制**
   - 最近任务中对 App 卡片下拉加锁（防止被清理）
4. 通知权限建议允许（前台服务通知可见，便于确认服务在运行）

## 四、手表端使用

1. 打开手表上的「滑动同步」应用
2. 顶部指示灯变绿 = 已连接手机端（红灯 = 未连接，检查手机端服务）
3. 在中间触控区**上下左右滑动**，每次滑动：
   - 手表短震动一次（发送成功）/ 长震动（发送失败）
   - 手机立即执行同方向滑动手势
4. **单次滑动模式**：一滑 = 一页（翻视频/翻页）
   **连续滑动模式**：按住拖动 = 连续滚动（浏览长列表）
   点底部按钮切换
5. 退出应用：点右上角 ✕（右滑手势已让给同步功能）

## 五、手机端设置项

- **滑动距离**（10%–60%）：滑动幅度，翻视频建议 25–35%，翻页可更小
- **滑动速度**：快 / 标准 / 慢
- **方向反转**：开启后手表上滑 = 手机下滑（部分滚动类 App 需要）
- **开机自启**：重启手机后自动恢复同步服务

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 手表显示"手机端未安装" | 手机端 APK 未装，或 APK 与 RPK 不是同一套（需用本包配套安装） |
| 手表显示"连接异常/未连接" | 手机端同步服务未启动；或小米运动健康未连接手表 |
| 手表滑动没震动 | 系统设置里确认振动开启；确认装的是 Redmi Watch 6 版 RPK |
| 手机没反应 | 无障碍服务未开启；或被系统杀后台（检查保活设置） |
| 滑动方向反了 | 手机端开启"方向反转" |
| 覆盖安装后连不上 | 手表端先卸载旧包再装新包（避免旧签名残留） |

## 七、隐私说明

- 手机端无障碍服务仅用于**执行**滑动手势（`canRetrieveWindowContent=false`），
  **不读取任何屏幕内容**
- 手表→手机只传输 4 种滑动方向 + 序号（约 40 字节/次），无任何个人数据
- 通信走小米官方穿戴通道（小米运动健康），不建立私有蓝牙连接，不影响原连接
